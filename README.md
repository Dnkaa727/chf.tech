# chf.tech

ИИ-платформа для проведения технических собеседований в финтехе.

## Запуск через Docker

Из корня репозитория выполните:

```bash
docker build -t chf-tech .
```

Запустите контейнер, передав ключ LLM:

```bash
docker run --rm \
  --name chf-tech \
  -p 5173:5173 \
  -p 8081:8081 \
  -e LLM_API_KEY="ваш-llm-ключ" \
  chf-tech
```

Откройте приложение:

```text
http://localhost:5173
```

Проверить backend:

```text
http://localhost:8081/health
```

При необходимости можно переопределить модель и сервис, предоставляющий модель:

```bash
docker run --rm \
  -p 5173:5173 \
  -p 8081:8081 \
  -e LLM_API_KEY="ваш-llm-ключ" \
  -e LLM_BASE_URL="https://api.openai.com/v1" \
  -e LLM_MODEL="gpt-4o-mini" \
  chf-tech
```

Остановить контейнер: `Ctrl+C`.

## Запуск через NixOS

В корне репозитория выполните:

```bash
export LLM_API_KEY="ваш-llm-ключ"
nix run .#all
```

Или запустите компоненты отдельно:

```bash
export LLM_API_KEY="ваш-llm-ключ"

nix run .#backend
nix run .#frontend
```

Приложение будет доступно по адресу:

```text
http://127.0.0.1:5173
```

Backend:

```text
http://127.0.0.1:8081/health
```


## Барс-интервьюер и озвучивание

В окне интервью отображается 2D-барс в костюме. Нажмите **«Включить голос»**:
он прочитает текущую реплику, затем будет последовательно озвучивать новые
вопросы, уточнения и обратную связь. Текст остаётся в чате. **«Повторить»**
заново читает последнюю реплику; **«Выключить голос»** останавливает речь и
автоматическое озвучивание. При завершении интервью итоговый экран открывается
после последней реплики; при ручном выходе звук останавливается сразу.

Озвучивание использует Web Speech API браузера и не требует нового API-ключа.
Нужен доступный русский голос: список и качество голосов зависят от браузера
и ОС. Предпочтение отдаётся локальному русскому голосу. Если голоса нет,
установите русский голос в настройках речи Windows и перезапустите браузер
или продолжайте в текстовом режиме. Голос включается явным нажатием кнопки;
микрофон для озвучивания не нужен. Ответы пользователя по-прежнему вводятся
текстом — распознавание речи не добавлено.

Движения рта привязаны к событиям воспроизведения речи, а не к отдельным фонемам.
При включённом системном уменьшении анимации движения отключаются.
Для обновления интерфейса в Docker пересоберите образ и пересоздайте контейнер.

Проверки frontend (Node.js 22.12+):

```bash
cd frontend
npm test
npm run build
```
