# Патч: сохраняем все цитаты-доказательства red flags

## Что меняется

1. Stage 2 получает более точные инструкции по выбору сегментов:
   - для `confidently_incorrect` нужно ссылаться на сегмент с конкретным ложным утверждением, а не на соседнюю правильную фразу;
   - для внутреннего противоречия `technical_contradiction` нужно включать обе (или все минимально необходимые) противоречащие части;
   - ID располагаются в порядке появления цитат в ответе.
2. В итоговом `red_flags` сохраняются все выбранные моделью доказательства в новом поле `evidence`.
3. Старое поле `quote` остаётся без изменений: оно по-прежнему содержит первую цитату и сохраняет совместимость с текущими потребителями API.
4. Все цитаты для `evidence` берутся из проверенных сегментов Python, а не генерируются заново моделью.
5. Добавлены тесты для пары противоречащих утверждений, точной цитаты `confidently_incorrect` и текста инструкции Stage 2.

## Установка

Извлеките архив в корень проекта `D:\RAG_BACKEND_ALL_25` с заменой файла `v3/engine.py` и добавлением нового теста `tests/test_v3_red_flag_evidence.py`.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m pytest tests/test_v3_red_flag_evidence.py -q
```

После локальных тестов повторите live-сценарий с противоречием и проверьте, что `technical_contradiction.evidence` содержит обе цитаты, а `confidently_incorrect.evidence` — именно ложное утверждение.

## Совместимость

Число запросов к LLM не меняется. Поле `quote` не удаляется и не переименовывается; добавляется только новое поле `evidence`.
