# Установка патча двухэтапной оценки

Патч рассчитан на архив `RAG_BACKEND_ALL_25(2).rar`, который был передан для интеграции.

## Перед установкой

1. Остановите Uvicorn (`Ctrl+C`).
2. Сделайте резервную копию папки проекта или хотя бы файлов, которые патч заменяет.
3. Не удаляйте и не заменяйте свой `.env`, `.venv` и API-ключ. Их в патче нет.

## Установка

1. Распакуйте содержимое ZIP **поверх корня** `D:\RAG_BACKEND_ALL_25`, сохранив структуру папок и согласившись на замену файлов.
2. В существующем `.env` добавьте или проверьте:

```dotenv
LLM_PIPELINE_MODE=two_stage
LLM_MESSAGE_MODE=system_user
LLM_JSON_MODE=schema
```

`LLM_PIPELINE_MODE=one_stage` временно включает прежний одновызовный evaluator для сравнения. После изменения `.env` перезапустите сервер.

## Проверка без платных запросов

Из PowerShell в корне проекта:

```powershell
python -m unittest discover -s tests -p "test_*.py"
python run.py check
python logic_probes_24.py --card PY-ASYNC-01 --compare
```

Ожидается: `156 tests ... OK (skipped=4)`, 25 карточек/рубрик, а offline-пробы сообщают об успешной сборке prompt без обращения к LLM. Четыре пропуска относятся к отдельным патчам рубрик RAG_LOGIC24/PG01: в исходном архиве их файлы лежат в папках патчей, но не установлены в канонический `data/rubrics_all_25.json`.

## Реальная проверка

Каждый ответ в `two_stage` делает **два платных вызова**: сегментация/маршрутизация, затем оценка. Сначала проверьте один синтетический ответ в пределах согласованного бюджета. Не отправляйте реальные персональные данные кандидатов в локальный MVP.

Подробная архитектура: `docs/TWO_STAGE_PIPELINE_RU.md`.
