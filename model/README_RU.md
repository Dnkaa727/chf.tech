# chf.tech — Python Backend AI-интервьюер / RAG v3

**Все 25 карточек имеют рубрики 0–10, индивидуальные уточнения и по 6 синтетических тестовых ответов плюс 2 red-team кейса.**

Быстрый старт: **[`START_HERE_RU.md`](START_HERE_RU.md)**.

Локально (без ключа):

```powershell
py run.py check
py run.py test
py run.py mock PY-ASYNC-01 partial
```

Для реальных LLM-тестов см. инструкцию. **Все 25 рубрик и тестовые ответы ещё требуют независимой экспертной валидации.** Число пройденных unit-тестов НЕ означает качество LLM.


## Двухэтапная оценка v3

По умолчанию v3 использует смысловую сегментацию ответа, маршрутизацию фрагментов по критериям и последующую оценку по ID доказательств (`LLM_PIPELINE_MODE=two_stage`). Старый одновызовный режим доступен для сравнения (`LLM_PIPELINE_MODE=one_stage`). Подробности: `docs/TWO_STAGE_PIPELINE_RU.md`.
